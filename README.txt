This is a "horror" mod I made with and for my kids. It's not really that scary,
it's more psychological over jump-scare. That said, there's some pretty creepy interactions
which are sometimes unexpected. You've been warned.

Sounds came from many talented creatives over at https://pixabay.com/sound-effects.
Their license is very generous, you should visit them for all your sound effect needs.

This mod was written with a lot of help from Codex. Like, almost all of it. It does a pretty
good job with Minecraft mods. I did start with tutorials from
https://www.youtube.com/@ModdingByKaupenjoe though. Super easy to follow if you want to take
a tutorial approach to building one of these things.
